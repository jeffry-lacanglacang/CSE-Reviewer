# Philippine Civil Service Exam (CSE) Reviewer 🇵🇭

An interactive, responsive web-based practice platform and full mock exam simulation designed to help candidates prepare for the **Philippine Civil Service Commission (CSC) Career Service Examination (Professional & Sub-Professional levels)**.

🔗 **Live Application:** [https://jeffry-lacanglacang.github.io/CSE-Reviewer/](https://jeffry-lacanglacang.github.io/CSE-Reviewer/)  
👤 **Compiled & Developed by:** Jeffry Lacanglacang  

---

## 🚀 About the Project

Passing the Civil Service Examination is a mandatory eligibility requirement for permanent positions in the Philippine government service. This web application provides a realistic testing environment modeled after official CSC standards. 

Whether you want to take a quick 10-question practice drill or test your endurance with a full 90-question simulation, this app provides immediate scoring, category-based performance analytics, and detailed step-by-step explanations.

---

## ✨ Key Features

*   **Comprehensive Question Bank:** Covers all primary competency areas tested in the official CSC Professional and Sub-Professional exams.
*   **Dual Test Modes:**
    *   *Quick Review:* Customizable 10-question sessions (by category or general).
    *   *Full Mock Exam:* Complete 90-question simulation testing your stamina under exam conditions.
*   **Live Session Timer:** Tracks your elapsed test time with a distraction-free **Focus Mode / Full-Screen** option.
*   **Realistic Passing Threshold:** Simulates the standard CSC **80% passing accuracy rate** with dynamic pass/fail scorecards.
*   **Detailed Analytics:** Breakdown of performance by specific category to identify your strengths and areas needing improvement.
*   **Comprehensive Answer Key:** Step-by-step explanations and solutions for every question after submission.
*   **Mobile-Friendly Design:** Built with Tailwind CSS for seamless use on smartphones, tablets, and desktop computers.

---

## 📚 Covered Competency Categories

The question bank is organized according to official CSC syllabi:

1.  **Numerical Reasoning:** Percentage calculations, word problems, fundamental operations, and number sequences.
2.  **Analytical Ability:** Word analogies, logical reasoning, and inductive/deductive syllogisms.
3.  **Verbal Ability (English & Filipino):** Vocabulary (synonyms/antonyms), grammar rules, spelling, and idiomatic expressions.
4.  **Reading Comprehension:** Passage analysis, inference drawing, and core message evaluation.
5.  **Paragraph Organization:** Logical sequencing of sentences to form coherent paragraphs.
6.  **Clerical Operations:** Filing rules, document handling, office correspondence, and basic administrative procedures.
7.  **General Information:** Philippine Constitution (1987), code of conduct for public officials (RA 6713), peace and human rights issues, and current environmental/general knowledge.
8.  **Graphs & Charts:** Data interpretation from statistical tables, bar graphs, pie charts, and trends.

## 🏃 Getting Started / Local Development

Since this project is built as a single-file static web application (`index.html`), running it locally requires no complex build tools or package managers.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/jeffry-lacanglacang/CSE-Reviewer.git
    ```
2.  **Navigate to the project folder:**
    ```bash
    cd CSE-Reviewer
    ```
3.  **Open `index.html`** in any modern web browser or run it via a local development server (such as Live Server in VS Code).
